# Site Capture

URLを1つ入れると、そのサイト内でたどれるページを巡回して、各ページのスクリーンショットを撮るローカルアプリです。
自分のPC（macOS）だけで動きます。

- 要件: [docs/requirements.md](docs/requirements.md)
- 設計: [docs/design.md](docs/design.md)
- 技術検証の結果: [docs/m0-findings.md](docs/m0-findings.md)

設計した機能（M0〜M6）はすべてできています。ブラウザの画面から撮影を始め、進み具合と結果を見られます。ログインが必要なページも撮れ、2回分の撮影結果を見比べられます。

## 準備（初回だけ）

Node.js 24 と pnpm が必要です。

```bash
pnpm install
```

```bash
pnpm --filter @site-capture/server exec playwright install chromium
```

## 起動する

```bash
pnpm start
```

- 画面をビルドしてからサーバーを起動し、ブラウザで http://127.0.0.1:4310 を開きます
- 終了するにはターミナルで `Ctrl + C` を押します（撮影中のページを撮り終えてから終了します）
- 画面でできること
  - 撮影履歴: 過去の撮影の一覧
  - 新しく撮影: URL・画面幅・巡回の範囲・ログインを選んで撮影を始める
  - 撮影結果: 進み具合をリアルタイムで表示。URLの階層や状態で絞り込み、画面幅を切り替えてサムネイルを見る。撮影中は停止できる。終わったら、失敗したページ（と止めたときに残ったページ）の撮り直し、同じ設定での撮影、ZIP（画像）・CSV（ページ一覧）の書き出し、削除ができる
  - ページ詳細: 画像を原寸または幅に合わせて表示。← → キーで前後のページへ移る
  - 比較: 2回分の撮影結果を、同じパスのページどうしで見比べる（下記）
  - 設定: ログイン状態の作成と削除、サイト設定の作成と編集（下記）

### 2回分の撮影結果を比べる

1. 「撮影履歴」で、比べたい撮影のカード左上のチェックを2つ付けて「比較する」を押します（古いほうが A、新しいほうが B になります）
2. 左の一覧からページを選びます。「追加」は B にだけあるページ、「削除」は A にだけあるページです
3. 表示方法を選びます
   - 左右に並べる: スクロールが連動します
   - 重ねる: 「A の濃さ」で透明度を変えられます
   - スライダー: 画像の上をドラッグすると、境目の左に A、右に B が出ます
- ← → キーで前後のページへ移れます。撮影結果の画面の「ほかの撮影と比較」からも開けます

### サイトごとの設定

「設定」の「サイト設定」で、サイトごとに次のことを決めておけます。撮影するURLのホストに合う設定が自動で使われます（撮影開始の画面で手で選ぶこともできます）。

- 撮る前に隠す要素（Cookie 同意バナー、チャットなど）。CSS セレクタか、ボタンの文字列で指定します
- 表示を待つ要素、スクロールしている領域（自動で見つからない場合）
- 撮影前に実行するスクリプト（ポップアップを閉じる、など）
- アクセス間隔と同時に開くページ数（アクセス制限の厳しいサイト向け）

Notion の公開ページ（`*.notion.site`）用の設定は最初から入っています。組み込みの設定は「複製」して自分用に直せます。

### ログインが必要なページを撮る

1. 画面の「設定」で、ログインするページのURLを入れて「ログイン用ブラウザを開く」を押します
2. 別のウィンドウでブラウザが開くので、いつもどおりログインします
3. 画面に戻って「ログイン状態を保存」を押します（ブラウザは自動で閉じます）
4. 「新しく撮影」で URL を入れると、同じサイトのログイン状態が自動で選ばれます

- 保存するのはログイン後の状態（Cookie など）だけで、パスワードは保存しません。保存先は `~/SiteCapture/auth/`（本人だけが読める権限）です
- ログインが切れていると、撮影結果の画面に「ログイン画面に転送されました」と表示されます。設定画面で作り直してください
- Basic 認証（ID とパスワードの入力画面が出るサイト）は、「新しく撮影」の「ログイン」欄で入力します。撮影の間だけ使い、保存しません

開発するときは `pnpm dev` を使います。サーバー（4310）と画面（http://127.0.0.1:5173 、変更がすぐ反映される）を同時に起動します。

## コマンドで1つのURLを撮る

```bash
pnpm capture https://example.com/
```

- 画像は `~/SiteCapture/captures/<ドメイン>/<撮影日時>/` に保存されます
- オプション
  - `--widths 1440,375`: 画面幅（カンマ区切り）。初期値は 1440 と 375
  - `--out <フォルダ>`: 保存先
  - `--expand-toggles`: Notion のトグルを開いて撮る
  - `--no-preset`: サイト用のプリセット（Notion など）を使わない
- Notion の公開ページ（`*.notion.site`）は、アクセス制限を避けるため1回の読み込みで全画面幅を撮ります。制限を受けた場合は 60秒 → 120秒 → 240秒 待って撮り直します

## コマンドでサイト全体を巡回して撮る

```bash
pnpm crawl https://example.com/
```

- 起点のURLから同じサイト内のリンクとサイトマップをたどり、見つけたページを撮ります
- 撮影結果は `~/SiteCapture/site-capture.db`（SQLite）に記録され、画像は `~/SiteCapture/captures/<ドメイン>/<撮影日時>/` に保存されます
- `Ctrl + C` で止められます（撮影中のページは撮り終えてから止まります）
- 主なオプション（すべては `pnpm crawl --help`）
  - `--max-pages 200`: 撮る最大ページ数
  - `--sample <n>`: 同じ階層のページ（ブログ記事など）は先頭 n 件だけ撮る
  - `--include-subdomains`: サブドメインも巡回する
  - `--keep-query`: パラメータだけが違うURLを別ページとして撮る
  - `--exclude <パターン>`: 除外するURLのパターン（`*` でワイルドカード）
- 保存先のルート（`~/SiteCapture`）は環境変数 `SITE_CAPTURE_HOME` で変えられます

## テスト

```bash
pnpm test
```

検証用ページ（`packages/server/test/fixtures/`）とテスト用サイト（`packages/server/test/helpers/site-server.ts`）を実際に Chromium で撮る結合テストと、API のテストを含むため、2分ほどかかります。

型チェックは `pnpm typecheck` で、3つのパッケージ（shared、server、web）をまとめて確かめます。
